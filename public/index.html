Themes same zip format as the booth: one folder per theme, one .md per combination, optional thumbnail.png and theme.txt

Foundations a block of text put in front of every prompt — drawing rules, style, safety. Each theme picks one (Normal / Big head / …); a run can override it.

Refine prompt — used by the "Refine" button on a result: the drawing and the original photo go back to the model with this instruction, for a clean-up pass
